# Public privacy policy

`privacy/index.html` and `privacy/privacy.css` are identical to the packaged bilingual privacy policy. They have no scripts, analytics or remote assets. `npm run build` synchronizes them from the extension.

After pushing this repository, enable GitHub Pages for branch `main` and folder `/docs`. Open the actual deployed `/privacy/` URL without signing in, verify both languages and support email, and only then enter that URL in Chrome Web Store. Do not claim deployment or invent a live URL before Pages reports success.
